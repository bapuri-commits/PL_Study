# PL_Study

C / C++ / Java 복습 프로젝트. 기본 문법 점검부터 고급까지 다시 다지고,
세 언어를 비교하며 "왜 이렇게 설계됐는지"를 정리한다. **C++가 메인.**

## 구성

```
PL_Study/
├── 00_MOC/          # 인덱스 허브 (Map of Content)
├── C/               # C 고유 주제 (시작 시 생성)
├── Cpp/             # C++ — 메인, 가장 깊게 (시작 시 생성)
├── Java/            # Java 고유 주제 (시작 시 생성)
├── Comparisons/     # 언어 교차 비교 (후반부 본격화)
├── Questions/       # 막힌 것·토론거리·미해결 스레드
└── _templates/      # 노트 양식
```

> 노트(`.md`)와 코드를 한 저장소에서 함께 관리하는 모노레포.
> 코드는 언어별 폴더 하위에 두고, 노트에는 짧은 스니펫 + 코드 경로 링크만 둔다.

## 워크플로우

거친 입력 → 같이 토론 → 합의된 결론을 마크다운으로 결정화.

- **모드 A (새 공부)**: 자유 형식으로 써온 글 → 같이 읽고 토론 → 결론을 깔끔한 마크다운으로 저장
- **모드 B (복습·심화)**: 같이 공부 → 스스로 정리 → 마크다운으로 다듬어 저장

> **토론이 먼저, 마크다운화는 마지막.** 받자마자 미화하지 않는다.
> 빈틈·오개념을 짚고 합의한 뒤에 정리한다.

## 외부 학습과의 경계

OOP / 디자인 패턴 / JVM / 알고리즘 / 자료구조는 별도 공부 중.
여기서는 **언어 문법 맥락에서 필요할 때만** 가볍게 연결하며,
그 주제 자체를 깊게 파지 않는다. ("거긴 어떻게 정리했어?" 식으로 연결)

