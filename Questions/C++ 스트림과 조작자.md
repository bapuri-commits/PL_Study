# Q. C++ 스트림과 조작자 — cin/cout, `<<`·`>>`, 조작자(endl·setw 등)

## 무엇이 궁금한가
- 원본글 질문2-2에서 "스트림을 본격적으로 다룰 때 하자"고 미뤄둔 스레드.
- `cin`/`cout` 객체의 정체, 삽입·추출 연산자(`<<`, `>>`), 스트림 조작자(`endl`, `setw`, `setprecision`, `hex` 등)의 동작 원리를 한 번에 정리한다.

## 내가 생각한 것 / 이미 닿은 것
- `endl` vs `'\n'`은 이미 닿음 — 둘 다 개행을 스트림에 넣지만 `endl`은 추가로 **버퍼를 flush**한다. (원본글 "헷갈리거나 몰랐던 것"에 정리됨.)
- `<<`·`>>`가 비트 시프트 연산자([[C 비트 연산]])와 같은 기호인데 스트림에선 뜻이 다르다 → **연산자 오버로딩**의 사례일 것이라는 짐작.

## 결론
> (미해결 — C++ 스트림/입출력을 본격적으로 다룰 때 재개)
- 다룰 거리: `cin`/`cout`/`cerr`가 무슨 객체인지, `<<`·`>>`가 어떻게 **연쇄(chaining)**되는지, 조작자(`endl`·`setw`·`setprecision`·`hex` 등)가 함수인지 객체인지, 버퍼링(flush 시점)과 성능(루프 안 `endl` 주의).
- 연결고리: `<<`·`>>`는 **연산자 오버로딩**(C++ 고유) → 연산자 오버로딩 정리와 이을 것. 버퍼/flush는 입출력·성능 정리와 연결.
