# Q. 정적/동적 바인딩 — 컴파일타임·런타임과의 관계, C++ virtual에서 본격화

## 무엇이 궁금한가
- 컴파일타임 vs 런타임, 그리고 정적 바인딩 vs 동적 바인딩의 차이가 무엇인가.

## 내가 생각한 것
- 처음엔 두 쌍을 같은 것으로 헷갈렸다.

## 결론
> 토론 후 정리. (미해결 — C++ 다형성·virtual 다룰 때 재개)
- **컴파일타임/런타임 = "시간대".** 컴파일타임은 기계어로 번역하는 동안, 런타임은 실행 파일이 실제로 도는 동안.
- **정적/동적 바인딩 = "이름↔대상 묶기가 그 시간대 중 언제 확정되느냐".** ([[언어란 무엇인가 — 분류와 컴파일·실행 모델]]의 "이름을 주소로 치환"이 바로 바인딩.)
    - 정적 바인딩 = 컴파일타임에 확정. C의 일반 함수 호출(`foo()`)이 여기 해당 — 컴파일러가 대상을 못 박는다.
    - 동적 바인딩 = 런타임에 결정. C++의 가상 함수(`virtual`)가 대표 — 부모 타입 포인터로 불러도 런타임에 실제 객체를 보고 어느 버전인지 고른다.
- 즉 바인딩은 시간축 위에서 벌어지는 한 종류의 사건이다. (컴파일타임 사건이 바인딩만 있는 건 아니다 — `sizeof`·`_Alignof` 계산도 컴파일타임 사건이지만 바인딩은 아님.)
- **보류 이유** — 동적 바인딩의 본격적 이해는 C++ 다형성/virtual, 즉 OOP 영역이다. [[지침]]의 외부 학습 경계에 따라 여기선 "C는 정적이 기본, C++에서 동적이 virtual로 들어온다"는 연결고리만 심어두고, C++ 다형성을 다룰 때 OOP 정리와 이어 재개한다.
