# Q. 컴파일러 동작 원리 더 깊게 — 컴파일러 수강 후 보강

## 무엇이 궁금한가
- 컴파일이 어휘 분석 → 구문 분석 → 이름을 주소로 치환(심볼 테이블) → 코드 생성 → 링크로 진행된다는 큰 흐름은 잡았다.
- "기계어는 이름이 아니라 주소로 식별한다"는 핵심도 이해함.
- 다만 각 단계의 내부 메커니즘(파싱 트리 생성, 최적화 단계, 코드 생성 전략 등)은 아직 깊이 모른다.

## 내가 생각한 것
- 프로그래밍 언어론에서 관련 내용을 일부 공부했으나, 컴파일러 과목은 아직 수강 전이라 전체를 다 알지는 못함.
- 식별자 이름이 그대로 기계어로 변환되는 줄 알았던 오해를 교정함 — 실제로는 심볼 테이블에서 이름→주소로 치환되고, 그 표는 컴파일 후 버려진다.
