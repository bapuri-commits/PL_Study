# Q. 어셈블리 직접 맛보기 — C 코드의 어셈블리 출력 읽어보기

## 무엇이 궁금한가
- C로 짠 간단한 코드(`c = a + b;` 같은)가 실제로 어떤 어셈블리로 변환되는지 눈으로 확인해보고 싶다.
- 목적은 "어셈블리로 뭔가 만들기"가 아니라, C 아래에서 무슨 일이 벌어지는지(레지스터, 스택, 함수 호출, 포인터의 실체) 이해하기 위함.
- 롤러코스터 타이쿤(크리스 소여, x86 어셈블리로 거의 1인 개발)처럼 "추상화를 벗어던진 극단적 사례"는 그 시대였기에 가능. 지금은 컴파일러 최적화가 사람보다 잘하는 경우가 많아 이해용 도구로만 접근.

## 내가 생각한 것
- 어셈블리가 근본 있고 멋있어 보여서 해보고 싶었음. 다만 큰 프로그램을 짜는 용도가 아니라 학습용이라는 점 합의함.

## 결론
> 토론 후 정리. (미해결 — 직접 실습 후 채울 것)
- 실습 방법: `gcc -S`로 어셈블리 출력을 뽑거나, Godbolt(Compiler Explorer) 같은 온라인 도구로 C ↔ 어셈블리를 나란히 보기.
- C/C++의 포인터·함수 호출·스택을 본격적으로 다룰 때 이 스레드를 다시 꺼내 연결한다.
