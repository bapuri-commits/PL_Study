## 수식과 연산자

### 연산자의 분류와 종류

- 수식(Expression)이란 피연산자(Operand)와 연산자(Operator)의 조합이다.

    1. 분류
        - 기능 : 대입, 산술, 부호, 증감, 관계, 논리, 조건, 콤마, 비트연산자, sizeof연산자, 형변환, 포인터, 구조체
        - 피연산자 수 : 단항, 이항, 삼항

### 논리 연산자

- 단축 계산
    - 논리연산자 사용 시 주의해야할 사안으로 다음과 같은 예시를 보면
    ``` C

    ( 2 > 3 ) && (++x < 5)
    ( 2 < 3 ) || (++x < 5)

    ```
    - and 연산은 첫 항이 거짓일 경우 두번째 항을 처리하지 않으므로 x값이 증가하지 않고 넘어갈 수 있다.
    - 또한 or도 마찬가지로 첫 항이 참일 경우 두번째 항을 처리하지 않으므로 x값이 증가하지 않고 넘어갈 수 있다.
    - 이를 단축계산이라 부르고 논리연산자 사용 시 조심해야 한다.

### 형변환

- 형변환에는 자동형변환과 명시적 형변환이 있고 자동형변환에 정수형변환, 대입형변환, 수식형변환이 있다.
  
    - 명시적 형변환

        1. 자동형변환에서는 자동으로 결과에 맞춰 자르거나 하위 자료형을 상위자료형으로 자동 변환하여 처리하였지만 프로그래머의 의도를 넣어 수동으로 형변환 연산자를 이용하여 처리할 수도 있다. 이를 캐스팅(Casting)이라 한다.
        2. 주의할점은 형변환 연산자를 사용한부분만 잠깐 변수나 범위에 해당하는 식의 결과의 자료형이 변화하는것이지 영구적인 것이 아니다.
        3. 당연히 같은계산도 명시적인형변환으로 인해 결과가 달라질 수 있다. 

### 연산자 우선순위

    - 콤마 < 대입 < 논리 < 관계 < 산술 < 단항 이다.

## 프로그램 제어문

    - 우리가 프로그램을 작성할 때 사용하는 기본적인 제어 구조는 세가지로 다음과 같다.
  
       1. 순차 구조(Sequence): 명령들을 순차적으로 실행하는 구조
       2. 선택 구조(Select): 둘 주의 하나의 명령을 선택하여 실행되는 구조
       3. 반복 구조(iteration): 동일한 명령이 반복되면서 실행되는 구조
